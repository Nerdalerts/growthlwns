# Usability Test Kit

## 1. Test Script & Tasks
**Introduction:**
"Hi, thank you for participating! We're testing a new design for an analytics dashboard. I'm going to ask you to complete a few tasks. There are no right or wrong answers—we're testing the system, not you. Please think aloud as you go so I can understand your thought process."

**Task 1: Cohort Retention**
- **Scenario:** You are a Growth Analyst checking monthly retention.
- **Task:** "Find the acquisition month that had the weakest retention by its 3rd month."
- **Success Criteria:** User successfully identifies the correct cell in the cohort heatmap and reads the value correctly.

**Task 2: Funnel Drop-off**
- **Scenario:** You are investigating user flow drop-offs.
- **Task:** "Identify which stage in the funnel has the highest drop-off rate. Can you find a way to see what segment (or group) caused the biggest drop?"
- **Success Criteria:** User identifies the correct stage and clicks on the relevant drill-down/segmentation filter.

**Task 3: A/B Test Results**
- **Scenario:** You are a Product Manager reviewing a recent experiment.
- **Task:** "Look at the A/B test results. Can you tell me if the test was successful? How confident are you in this result, and was there enough data?"
- **Success Criteria:** User correctly interprets the effect size, confidence interval, and sample size warnings.
